## What I Learned

### What is FastAPI?

FastAPI is a modern Python framework used to build APIs.

Key learnings:

* Fast to develop.
* High performance.
* Automatic API documentation.
* Strong typing support through Python type hints.
* Widely used in AI and machine learning applications.

Why we are using it:

* Excellent integration with AI systems.
* Easy to learn.
* Production-ready.
* Popular in startups and AI-focused companies.

---

### What is PostgreSQL?

PostgreSQL is an open-source relational database.

Key learnings:

* Stores structured application data.
* Supports complex queries.
* ACID compliant.
* Highly reliable and scalable.

Why we are using it:

* Industry standard database.
* Suitable for financial and portfolio data.
* Strong ecosystem.
* Scales well from small projects to enterprise applications.

---

### What is Docker?

Docker is a containerization platform.

Key learnings:

* Packages applications with all dependencies.
* Ensures consistent environments.
* Makes deployment easier.
* Simplifies onboarding and scaling.

Why we are using it:

* Allows the platform to run consistently everywhere.
* Simplifies local development.
* Makes cloud deployment easier.
* Standard practice in modern software companies.
